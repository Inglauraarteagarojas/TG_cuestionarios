Guía práctica: Earth Engine y Colab

Antes de comenzar. Esta guía utiliza el acceso no comercial de Earth Engine para estudiantes que cumplan los requisitos de Google. El código de Google Colab usa un proyecto Cloud registrado: cada estudiante debe introducir su propio ID. Los enlaces a la consola no crean ni autorizan credenciales por sí solos.

Objetivo de la práctica

08

Autenticarse e inicializar Earth Engine

Crea la primera celda de código y pega el bloque siguiente. Sustituye ID_DE_TU_PROYECTO por el ID que registraste, por ejemplo ee-mi-proyecto-academico. Ejecuta la celda; selecciona tu cuenta, revisa la solicitud de acceso y concede los permisos necesarios para el ejercicio. No compartas códigos de autorización, tokens ni credenciales. En Colab, el flujo oficial suele abrir una ventana de autenticación.

import ee
import geemap

ee.Authenticate()
ee.Initialize(project='ID_DE_TU_PROYECTO')
print('Conexión con Earth Engine establecida')
Si import geemap falla, ejecuta %pip install -q geemap en una celda, reinicia la sesión si Colab lo solicita y vuelve a importar. Google Colab suele incluir Earth Engine y geemap preinstalados.
09

Cargar CHIRPS y representar la precipitación

Crea otra celda y ejecuta el bloque completo. filterDate incluye el 1 de mayo y el 2 de mayo de 2018 porque la fecha final, 3 de mayo, se excluye. sum() calcula la precipitación acumulada de ambos días y clip() limita la visualización al círculo de estudio. La escala de colores es una configuración visual de 0 a 30 mm: no implica que ese sea el rango real de los datos.

# Zona de estudio: punto de referencia y radio de 20 km
sumapaz = ee.Geometry.Point([-74.208, 4.285]).buffer(20000)

# Dos días completos: 1 y 2 de mayo de 2018
# La fecha final de filterDate es exclusiva.
dataset = (
    ee.ImageCollection('UCSB-CHG/CHIRPS/DAILY')
    .filterDate('2018-05-01', '2018-05-03')
    .filterBounds(sumapaz)
)

print('Número de imágenes:', dataset.size().getInfo())

# Precipitación acumulada del período (mm)
precipitation = (
    dataset.select('precipitation')
    .sum()
    .clip(sumapaz)
)

precipitation_vis = {
    'min': 0,
    'max': 30,
    'palette': ['001137', '0aab1e', 'e7eb05', 'ff4a2d', 'e90000']
}

# Mapa satelital (no utiliza OpenStreetMap)
m = geemap.Map(
    basemap='Esri.WorldImagery',
    center=[4.285, -74.208],
    zoom=10
)
m.add_layer(
    precipitation,
    precipitation_vis,
    'Precipitación acumulada Sumapaz (mm)',
    opacity=0.7
)
display(m)

La capa es una estimación de precipitación basada en datos CHIRPS, no una medición puntual en cada lugar. El círculo de 20 km es un área de práctica y no representa el límite administrativo oficial de Sumapaz.

10

Examinar el mapa y calcular un resumen

En el resultado aparecerá un mapa base satelital con una capa circular de colores. Usa los botones de zoom y control de capas. Como ejercicio complementario, calcula la media espacial de la precipitación acumulada; este número resume el área, pero no reemplaza las diferencias visibles entre píxeles.

# Precipitación media espacial en la zona (mm acumulados)
resultado = precipitation.reduceRegion(
    reducer=ee.Reducer.mean(),
    geometry=sumapaz,
    scale=5566,
    maxPixels=1e8
)
print('Precipitación media acumulada (mm):', resultado.getInfo())

Comprobación y fuentes

Comprobación de aprendizaje

  1. ¿Cuál es la diferencia entre el nombre y el ID de un proyecto de Cloud?
  2. ¿Por qué no se necesita crear una clave API para usar ee.Authenticate() en Colab?
  3. ¿Por qué el filtro termina en 2018-05-03 si se analizan dos días?
  4. ¿Qué significa sumar imágenes con precipitación diaria expresada en mm/día?
  5. ¿En qué se diferencia la resolución de CHIRPS del tamaño del área delimitada?

Solución de problemas frecuentes

  • Proyecto no encontrado o sin permisos: comprueba el ID, la cuenta, el registro no comercial y la API habilitada.
  • Mensaje de autorización: vuelve a ejecutar ee.Authenticate() y acepta los permisos con la cuenta correcta.
  • No aparece el mapa: ejecuta las celdas en orden; comprueba dataset.size().getInfo() y la instalación de geemap.
  • Colores saturados: ajusta el parámetro max tras revisar los datos; no cambia los valores de precipitación.
  • Se reinició Colab: repite la autenticación e inicialización de la sesión.
